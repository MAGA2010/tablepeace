# TablePeace user checks

Run five short sessions with people who plan activities with classmates or friends. Ask for permission to take notes. Do not collect names, contact details, raw private requirements, or screenshots containing them. Explain that this is a prototype and that venue facts are fictional.

## Session tasks

Give each participant the same two planning tasks in a different order across sessions:

1. **Manual mode:** join a four-person room, enter a time, maximum cost, and setting requirement, then review a proposed plan.
2. **AI-assisted mode:** in a separate fictional room, consent to sending a short note, inspect the AI draft, correct it if needed, and save the requirements.

Do not coach after reading the task. If someone is stuck, record the point where they stop and only then offer help so the session can continue. Do not ask participants to use a real disability or medical need; test unsupported needs with a clearly fictional example.
